## 🌐 Accessing E-Resources

### E-Resources Portal: MyLOFT (My Library On Finger Tips)

> Remote access platform for world-class collection of e-books and e-journals.

#### Setup Instructions

**For Laptop/Desktop:**
1. 🌐 Use **Chrome** or **Microsoft Edge** browser
2. ⬇️ Download MyLOFT app from [https://app.myloft.xyz/](https://app.myloft.xyz/)
3. 💾 Save to your computer

**For Smartphone:**
1. 📱 Go to Google Play Store (Android) or App Store (iPhone)
2. ⬇️ Download **MyLOFT app**
3. ⚙️ Accept VPN Config request when prompted
4. 🔧 Disable Private DNS in phone settings *(required for remote/off-campus access)*
5. ✅ Works on: Android 10+; iPhone 13+

#### Login Process

1. 🔓 Open MyLOFT app on your device
2. 🏫 Type **"KCA"** and select from available institutions
3. 👤 Login with your **KCAU email** as username
   - *New users*: Click "Sign-up" and enter personal details
   - ⚠️ Requests using non-KCAU email will be rejected
4. ✉️ Account activation approved within 24 hours; confirmation sent to KCAU email
5. 🔐 Use confirmation link for first-time login; update credentials as needed
6. ➕ Accept MyLOFT "Add-on extension" when prompted by browser

#### Accessing Content

| Content Type | Navigation Path |
|-------------|----------------|
| 📚 All E-Resources | Menu → E-resources → Select category |
| 📖 E-Books | E-resources → All Databases → ProQuest eBooks Central / Taylor & Francis / DOAB |
| 📰 E-Journals | E-resources → All Databases → JSTOR / EBSCO / Emerald / Taylor & Francis / Wiley / IEEE |
| 📝 Past Exam Papers | E-resources → Past Papers Bank → Filter by unit/unit code |

#### Downloading E-Books

## 🔄 Circulation Procedures

### Eligibility

| Requirement | Detail |
|-------------|--------|
| 👤 Account Registration | Users must register for Borrower's Account with Library Management System |
| 🆔 Identification | Valid Student or Staff ID required for borrowing |
| 💰 Professional Programs | Proof of caution fee payment required (refundable at course end) |
| ✅ Cost | Accounts created free of charge for qualified University community members |

### Borrowing Privileges

- 🎫 Privileges granted upon presentation of valid ID
- 🔒 Privileges **not transferable**; subject to withdrawal if abused
- 📦 Borrower responsible for materials until returned in good condition

### Suspended Accounts

Accounts blocked under these conditions:

| Condition | Description |
|-----------|-------------|
| 💰 Outstanding Fines | Unpaid overdue penalties |
| ✅ Clearance Submitted | User has presented clearance forms and been cleared by Head of Library Services |
| 📚 Unreturned Items | Items from previous semester/trimester not returned |
| 📋 Registration Lapse | User has not registered for new semester/trimester |
| 💸 Caution Fee Withdrawn | User has withdrawn their caution fee deposit |
| ⚠️ Pending Cases | Unresolved issues with the Librarian |

### Checking-Out Items: Step-by-Step

1. 🔍 **Search**: Use OPAC to retrieve desired material from collection
2. 🪪 **Present ID**: Bring ID (acts as borrower card) + item to Loans/Return desk
3. 📡 **Scan ID**: Librarian scans ID barcode to access your account via Circulation Module
4. 📦 **Check Out**: Librarian scans item barcode; system verifies match with presented item
5. ⏰ **Loan Period Set**: System auto-sets loan period based on item type + user category; sends email alert
6. 🏷️ **Due Date Stamp**: Librarian stamps system-generated due date on book label
7. ✅ **Complete**: Item legitimately borrowed; user may exit library with material

### Checking-In Loaned Items

1. 📦 **Present Item**: User brings material to Loans/Return desk
2. 📡 **Scan Barcode**: Librarian scans item barcode to CHECK IN via Circulation Module
3. ✅ **Verify Match**: System records checked against presented item; verbal acknowledgement given
4. 📧 **Confirmation**: Email alert sent to user; due date cancelled on returned item
5. 🗂️ **Sorting**: Item placed in sorting bay awaiting shelving

> ⏰ Borrowing/Return open until **5 minutes before library closing time**

### Renewals/Loan Extension

**Methods:**

| Method | Process |
|--------|---------|
| 🌐 Online Self-Service (OPAC) | Login → Select items → Click Renew/Renew All → System generates new due date |
| 📧 Email Request | Email Library with Title, Author, Call Number; must be sent on/before due date |
| 🗣️ Face-to-Face | Visit circulation desk with ID; librarian extends loan period |

**OPAC Renewal Steps:**
1. Visit [http://opac.kcau.ac.ke](http://opac.kcau.ac.ke)
2. Login: Username = University ID (without slash, e.g., 1700540); Password = National ID
3. View checked-out items with Title, Author, Due Date, Renew Options
4. Tick items to renew → Click "Renew" or "Renew All"
5. System auto-generates new return date(s)

**System Will NOT Renew If:**
- ❌ Another user has placed the item on hold
- ❌ Item is already overdue
- ❌ User has exhausted renewal chances for that item

### Recalls

> Library may recall loaned items before due date if:
- 🎯 Another user has reserved the item
- ⚡ Item required immediately for urgent academic need

### Reservations/Holds

**To Place a Hold:**
1. 🔐 Login to OPAC account at [http://opac.kcau.ac.ke](http://opac.kcau.ac.ke)
2. 🔍 Search for item title in "Search for items" box
3. 🎯 Click "Hold" option on right side of retrieved item page
4. ✅ Receive system confirmation prompt

**After Return:**
- 📧 Email notification sent when reservation is filled
- 🕐 Reserved items held at Loan/Return desk for **maximum 48 hours**
- 🔄 After 48 hours: item re-shelved or circulated to next waiting customer
